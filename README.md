# Duner Box

Сайт за Duner Box — ул. Търговска 77, Козлодуй. С онлайн поръчки за доставка до АЕЦ Козлодуй (8:00–10:00, пон–пет).

- `npm run dev` — локален сървър с автоматично презареждане → http://localhost:5173
- `npm start` — локален сървър
- `npm test` — Playwright тестове (компютър + телефон + API)
- `npm run screenshots` — screenshots в папка `screenshots/`

## Меню и цени
Всичко е в `menu-data.js` (ползва се и от сайта, и от сървъра). `price: null` = „цена скоро“.
Часовете за поръчки са в `ORDER` в същия файл.

## Поръчки и имейли (Resend)
Сайтът и сървърът са в Cloudflare Worker (`cloudflare/worker.js`, публикуване: `npm run deploy`).
`api/order.js` проверява часа на сървъра, смята цените сама, записва поръчката (вижда се в панела)
и праща на клиента имейл „Получихме поръчката“ с номера ѝ. Собственикът **не** получава имейли —
работи от панела, а клиентът получава имейл и когато поръчката бъде приета или отказана.
Отговорите на клиентите (poruchki@dunerbox.bg) се препращат към dunerbox77@abv.bg.

Тайни в Cloudflare (`npx wrangler secret put …`):
| Име | Пример |
|---|---|
| `RESEND_API_KEY` | `re_...` (без него — тестов режим, имейлите само се логват) |
| `RESEND_FROM` | `Duner Box <poruchki@dunerbox.bg>` (домейнът трябва да е верифициран в Resend) |
| `ORDER_SECRET` | дълъг случаен низ (подписва входа в панела) |
| `ADMIN_PASSWORD` | паролата за панела |

Снимки на напитките, ориза и шиша: Pexels (безплатен лиценз).

## Панел за поръчки — dunerbox.bg/admin

Собственикът вижда поръчките на живо, приема/отказва (клиентът получава имейл) и отбелязва „Доставена“.
Звъни, докато има чакащи поръчки; може да се добави на началния екран като приложение.
Това е единственото място, където идват поръчките — трябва да е отворен между 8:00 и 10:00.

- Парола: `npx wrangler secret put ADMIN_PASSWORD` (смяната ѝ изхвърля всички влезли устройства).
- Код: `admin.html`, `admin.css`, `admin.js`, `admin-sw.js`, `admin.webmanifest`, сървър — `api/admin.js`.
- Тестов Worker: паролата е `test-panel` (в `wrangler.jsonc`, само за тестовите данни).
