# Duner Box

Сайт за Duner Box — ул. Търговска 77, Козлодуй.

- `npm run dev` — локален сървър с автоматично презареждане → http://localhost:5173
- `npm start` — локален сървър
- `npm test` — Playwright тестове (компютър + телефон)
- `npm run screenshots` — screenshots в папка `screenshots/`

Менюто и цените се редактират в началото на `script.js`.
